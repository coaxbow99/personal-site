# My Personal Site (Frutiger Aero / Nostalgia Theme)

A personal website built from scratch using custom HTML and CSS. The site features a nostalgic, early-2000s desktop operating system aesthetic, blending tech nostalgia with nature visuals inspired by the Frutiger Aero design movement.

## 🚀 Submission Requirements Checklist

- **HTML + CSS:** Handcoded layout utilizing semantic HTML tags and fully custom CSS styling.
- **Fully Deployed:** Hosted publicly and live at [coaxbow99.github.io](https://github.io).
- **At Least 3 Sections:** Features structured sections including a main landing area, an **About Me** section, a **Projects** log, and a **My Favourites** gallery.
- **Custom CSS & Creativity:** Styled with custom fonts, glassmorphism elements, drop shadows, and a unique window container meant to mimic a classic desktop notepad app.
