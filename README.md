## My Personal Site (Frutiger Aero / Nostalgia Theme)

A personal website built from scratch using custom HTML and CSS. The site features a nostalgic, early-2000s desktop operating system aesthetic, blending tech nostalgia with nature visuals inspired by the Frutiger Aero design movement.

### 🚀 Submission Requirements Checklist

* **HTML + CSS**: I handcoded the whole layout using semantic HTML tags and wrote all the custom CSS styling myself.
* **Fully Deployed**: The site is hosted publicly and you can see it live right here at coaxbow99.github.io.
* **At Least 3 Sections**: It includes structured pages like a main landing area, an About Me section, a Projects log, and a My Favourites gallery.
* **Custom CSS & Creativity**: I styled it using custom fonts, glassmorphism elements, drop shadows, and a unique window container designed to look like a classic desktop notepad app.

### 🤖 AI Usage Disclosure

In compliance with Requirement #6:

* **How AI was used**: I used AI purely as a helper assistant to debug responsive layout breaking points and to improve CSS text-contrast parameters against busy backgrounds.
* **What was hand-coded**: I wrote and designed everything else completely from scratch independently. This includes all core HTML structures, layout concepts, component assets, and thematic styling rules.
